# 游戏概述

数字华容道是一种经典的益智游戏，玩家需要通过移动方块，将打乱的数字重新排列成正确的顺序。游戏目标是将数字按照从小到大的顺序排列，空格位于最后。

规则如下：

游戏面板由 n×n 的方格组成；
每个方格包含 1 到 n²-1 的数字，以及一个空格；
可以点击与空格在同一行或同一列的数字，让中间一整段数字一次滑向空格（点击单个数字会使数字移向空格处）；
当所有数字按顺序排列（1 到 n²-1），且空格在最后时，游戏获胜。

# 状态空间

n*n数字矩阵构成状态空间，其中每个元素取值为1~n^2-1.

# 动作空间

离散的。可移动所有旁边有空格的数字。

# 奖励设置

每移动一步（即玩家点击）-1分；

数字归位一次+5分（每个数字仅限一次）。

# 环境目标（终止状态）

所有数字归位，或者累积步数达到最大值。
