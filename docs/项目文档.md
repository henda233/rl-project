# 项目背景与目标

自定义2D物理环境并设计奖励规则，将其用于强化学习任务，训练一个取得高分的智能体（最优策略）。

# 技术栈

使用python3.12开发。环境使用虚拟环境，相关命令`uv venv`、`uv pip`等。

只能使用如下依赖库，除此之外不能使用其他任何现成的依赖库：

- numpy：基础运算库
- pytorch：深度学习库，禁止使用现成的强化学习模型、算法
- tqdm
- matplotlib
- gymnasium：强化学习环境搭建

# 需求

## 1. 搭建强化学习任务环境

使用gymnasium的预设环境：MountainCar-v0。其背景是一辆车被随机放置在正弦波形山谷的底部。唯一的可用动作为向两个方向加速。该 MDP 的目标是策略性地加速车辆以到达右侧山顶的目标状态。

## 2. 实现强化学习算法

结合环境实现Actor-Critic算法。可参考`examples/actor_critic_example.py`，注意该脚本使用的是gym，本项目使用的是gymnasium，注意API差异。

## 3. 运行

运行环境和算法，开始智能体训练，得到最优策略。训练过程中，给出环境画面。训练结束后，绘制迭代数-累积回报曲线图。

## 4. 其他

随着项目开发，会增加新的需求。
