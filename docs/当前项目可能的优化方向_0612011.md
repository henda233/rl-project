目前项目的DeepCubeA算法采用“外层固定目标值+内层批量更新”的方式，解决了深度近似值迭代（DAVI）的“移动靶”问题。但是，loss抖动问题已经被解决，随之而来的是loss不收敛问题，即外层的loss持续上升（虽然内层在下降）。

经过我的研究发现，导致loss不收敛的**可能**原因是：一是训练迭代次数不足，或者说模型的训练时间短；二是训练集样本数量少（目前20万个样本），没有覆盖尽可能多的数据分布情况；三是模型架构深度不足，难以拟合庞大的数据集。

经过测试对比发现，解决移动靶问题后的模型在测试集上的简单档胜率优于未解决移动靶问题后的模型：

但是它们都无法达到100%胜率，中高档更是胜率为0.

有如下优化方向：

1. 动态调整早停耐心值：随着外层迭代次数增加，逐步增大 DEEPCUBEA_INNER_PATIENCE，给模型更多时间去适应后期的复杂目标。
2. 引入学习率调度器：在内层训练中使用余弦退火或阶梯式学习率衰减，让模型在后期能更精细地拟合目标。
3. 目标值平滑：在外层计算目标时，可以采用软更新或滑动平均的方式，减少单次 Bellman 备份带来的剧烈波动。
4. 神经网络结构优化：添加批量归一化层（BN），适当增加神经元数量。
5. 动态获取状态序列（数据分布偏移问题）：现在的项目是离线获取大量的状态序列作为数据集，可以尝试改为：在内层训练前，随机采样获取状态序列作为当前的数据集。
