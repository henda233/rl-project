# PPO 并行训练需求

## 需求描述

实现 PPO 并行训练，即同时开启多个环境，同时训练多个智能体，每个环境智能体使用的势能函数的 k 值不同。

## 需求要点

- 方案 A：独立智能体并行（N 个完全独立的 PPO agent，各自拥有独立网络参数）
- 并行环境数量作为参数加入 config.py
- k 值：确定起始值 + 间隔值，每个环境取一个间隔
- 在同一张图上对比所有 k 值的训练曲线（原始 return + 塑形 return 双图）
- 自动选出最优 k 值
- 保存训练过程中最好的模型参数到 results/models/ 目录
- episode 数保持 500
