# 需求：DeepCubeA 在线采样 + 轻量验证指标

## 背景

当前 DeepCubeA v2 采用离线固定 20 万状态集 + 批量更新 + 固定目标 AVI 训练。解决了"移动靶"问题后，Short 档胜率从 38% 提升到 47%，但 Medium/Hard 档胜率为 0%，且外层 loss 持续上升。

## 需求描述

将离线固定数据集训练改为**在线采样 + 混合策略**，在训练过程中动态生成状态，解除分布固化问题。同时在 `deepcubea_search.py` 中新增轻量验证指标，替代训练过程中的完整 A* 搜索评估。

## 关键决策

1. **混合采样策略**：每轮外层迭代从基础数据集采样 B' 个 + 在线生成 B 个新状态，B/B' 作为 config 参数
2. **不做 ε 阈值**：ε 阈值超参数依赖过强，不采用
3. **K 保持 500**：打乱步数参数不变
4. **种子可控**：外层迭代随机种子参数化，相邻轮次采样有一定重叠
5. **默认轻量 + flag 完整 A\***：评估脚本默认跑轻量指标，完整 A* 由 flag 开启
6. **验证集动态生成**：不持久化文件，种子参数化保证可复现
7. **网络架构**：BN 纳入本计划，网络容量扩展由用户独立调整
