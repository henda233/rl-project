# 需求：实现数字华容道游戏环境

## 需求描述

基于 `docs/数字华容道游戏环境设置.md` 的设计文档，实现一个数字华容道自定义强化学习环境。

## 核心规则

- n×n 方格面板（n 可配置），包含数字 1 到 n²-1 及一个空格
- 只能点击空格上下左右相邻的方块，方块滑入空格（标准玩法）
- 目标状态：数字 1 到 n²-1 按序排列，空格在最后

## 环境规格

| 项目 | 规格 |
|---|---|
| 状态空间 | n×n 矩阵，展平为 (n²,) 的 Box |
| 动作空间 | Discrete(4)：上/下/左/右（空格移动方向） |
| 奖励 | -1/步 + 每个数字首次归位 +5（每 episode 仅一次） |
| 终止条件 | 全部归位 或 达到最大步数 |
| 初始状态 | 正向打乱（从目标状态执行 N 次随机合法移动） |

## 可配置参数

- `HUARONGDAO_N`：棋盘大小 n，默认 3
- `HUARONGDAO_MAX_STEPS`：最大步数，默认 200
- `HUARONGDAO_SHUFFLE_STEPS`：打乱次数，默认待定

## 渲染

支持 ansi / rgb_array / human 三种渲染模式。

## 交付物

- `env_digital_huarongdao.py`：环境实现
- `config.py` 新增相关参数
