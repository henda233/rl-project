# 需求：PPO + DeepCubeA J(s) 势函数塑形探索

## 需求描述

探索将 DeepCubeA 的启发函数（代价函数）J(s) 作为强化学习内在奖励的可行性与预期效果，不采用启发式搜索算法，直接进行 PPO 强化学习。

## 具体内容

1. 分析方案 A（势函数塑形 r_int = J(s) - J(s')）和方案 B（状态惩罚 r_int = -J(s)）的理论差异
2. 分析与 PPO 联合训练的可行性（J(s) 训练 + PPO 策略训练交替）
3. 预估 PPO + J(s) Shaping 相比 DeepCubeA A* 搜索的优劣

## 关键结论

- 方案 A（势函数塑形）理论上优于方案 B：直接评估动作后果，而非仅评估状态
- 联合训练存在三重风险：冷启动陷阱、双重正反馈雪崩、非平稳数据分布
- 推荐路径：先冻结 J(s) 验证前提，再松散阶段性联合训练
- PPO 无法替代搜索的"前瞻"纠错能力，但短距推理更快
