# 执行计划：DeepCubeA 加权 A* 搜索求解

## 背景

DeepCubeA 的第二阶段：加载训练好的神经网络作为启发函数 h(s) = J(s)，使用加权 A* 搜索从打乱状态求解。

加权公式：

```
f(s) = λ · g(s) + h(s)
```

- λ = 1：退化为标准 A*，保证可纳性
- λ < 1：降低路径代价权重，更依赖启发函数，搜索更贪婪

## 搜索流程

1. 从打乱状态 s0 出发，初始化优先队列，f(s0) = λ·0 + J(s0)
2. 每次弹出 f 值最小的节点
3. 若当前节点为目标状态 → 回溯路径，返回解
4. 否则展开所有合法动作，计算后继状态的 f 值，入队
5. 若队列为空 → 求解失败
6. 可选：设置最大展开节点数以限制搜索时间

## 验收标准

- **主指标**：胜率 = 求解成功数 / 测试状态数，目标 ≥ 目标值（待定）
- **辅助指标**：平均求解步数、平均展开节点数

## 风险与约束

- **风险**：若神经网络启发函数质量不足，加权 A* 可能无法在合理时间内求解远距离状态（展开节点数爆炸）
- **风险**：λ=0.3 更依赖启发函数，若启发函数偏差较大可能导致次优解甚至失败
- **约束**：搜索仅展开合法动作，避免无效状态
- **约束**：需记录路径（父子关系）以支持回溯

2. 在 100 个随机打乱状态上运行批量评估
3. 统计胜率、平均求解步数、平均展开节点数
