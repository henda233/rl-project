# 摘要：DeepCubeA 算法研究

## 核心结论与关键信息

- **问题规模**：4×4 数字华容道约 1.046×10^13 状态，常规强化学习（PPO等）难以找到最优策略，需大量真实环境交互，试错成本极高
- **首选方法**：启发式搜索，f(s) = g(s) + h(s)，其中 h(s) 为启发函数（从 s 到目标的代价估计）
- **DeepCubeA 核心**：近似值迭代训练 DNN → 逼近未来代价函数 J(s) → 作为启发函数 h(x) → 加权 A* 搜索求解
- **训练方式**：从目标状态反向随机移动生成数据集，(s, J'(s)) 作为训练样本，MSE loss 做梯度下降
- **值迭代公式**：J'(s) = min_a (1 + J(A(s,a)))，即贝尔曼最优方程的一步更新
- **加权 A***：f(x) = λ·g(x) + h(x)，λ∈[0,1]；λ=1 为标准 A*，λ<1 更贪婪依赖启发函数
- **网络结构**：2 个全连接隐藏层 → 4 个残差块 → 1 个线性输出单元

## 内容概述

> 研究文档分析了数字华容道问题的规模，论证了启发式搜索优于常规 RL。介绍了 DeepCubeA 的完整工作流：近似值迭代训练 DNN → 加权批量 A* 搜索求解。给出了损失函数、值迭代公式、网络结构定义。
